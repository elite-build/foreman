# codex fixtures

Traffic recorded from the real `codex app-server` (JSON-RPC lines on stdio) by `npm run record:agent -- codex <scenario>`, one `<scenario>.jsonl` per scenario (docs/agents.md, section 9.1). `plain`, `approval`, `question`, `plan`, `steer`, `interrupt`, `crash`, `resume`, `fork`, `revert`, `compact`, `goal`, `goalclear` and `sandbox` (a Windows app-server's start-up, with `windowsSandbox/readiness`, answered `notConfigured` in the recorder's new CODEX_HOME), `scoped` (held to a persona's `writes`; recorded with `[windows] sandbox = "unelevated"` in that home, so readiness is `ready`) are recordings; `limit` is `plain` with the frames a usage limit produces substituted (`edited`, its header lists them). The header names the CLI version and model. `tests/replay/codex.test.ts` plays each through the real driver; `tests/agentFixtures.test.ts` checks none holds a path, key, email or JWT.
